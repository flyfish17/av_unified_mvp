# Node-RED 客户演示脚本（5 分钟版 / 销售现场用）

**目标**：让客户在 5 分钟内看见「拖一个节点就能改 AI 行为」的低代码集成体感。

**前置条件**（销售不用记，运维已经布好）：
- 3588 已运行 supervisor + Node-RED `:1880` + dashboard `:8800`
- 客户大屏打开 `http://192.168.5.6:8800`（总览页第一块就是 Node-RED 中控嵌入帧）

---

## 一句话开场（30 秒）

> "我们的语音/视觉理解结果是用 **标准 MQTT 协议**喷出来的——任何懂拖拽的工程师都能在浏览器里把这些事件接到任何业务动作上。下面演示。"

---

## 步骤 1：先让客户看现有效果（1 分钟）

打开总览页大屏。指着 Node-RED 中控帧（位于总览页第一块）说：

> "这是 Node-RED 编排面板。当前已经接了两条主链路：**Ai孪生**（视觉+语音双通道融合判断）和 **CREATOR AI**（语音 + Siri 联动）。"

对着大屏念一遍语音指令，比如「打开会议模式」。客户会同步看到：
- 总览页转写卡出现带标点的句子
- Node-RED 帧里 debug 侧栏闪一下（命令被订阅到）

---

## 步骤 2：开编辑器，找入口节点（1 分钟）

点 Node-RED 帧右上角的 `↗` 跳到编辑器 `http://192.168.5.6:1880/`。

切到 **Ai孪生** tab。指给客户看左上的 `mqtt in` 节点：

> "这就是入口——`av/audio/command_punctuated`。每一句客户说的话，带标点、带时间戳，都会从这个节点冒出来。"

双击节点，把 topic 截图给客户看：

```
av/audio/command_punctuated
```

> "标准 MQTT。任何系统——OA、ERP、楼控、第三方 IoT 平台——都能直接订。我们不用给你接 SDK。"

---

## 步骤 3：拖一个 function 节点，加一条客户场景规则（2 分钟）

**演示动作**：从左侧 palette 拖一个 `function` 节点放到 `av/audio/command_punctuated` 后面，连线。双击编辑：

```javascript
// 客户场景：听到"巡检"两个字就推一条消息到对讲系统
if (msg.payload.text && msg.payload.text.includes("巡检")) {
    return {
        topic: "av/control",
        payload: {
            target: "intercom",          // 客户的对讲系统名
            action: "broadcast",
            params: { text: "收到巡检指令，请上报位置" }
        }
    };
}
return null;  // 其他句子不动
```

后面接一个 `mqtt out` 节点，topic 留空（function 里已带），broker 用默认的 `mosquitto:1883`。

**点 Deploy**（编辑器右上角红色按钮）。

> "好——刚才那 30 秒里，我们就给系统加了一条客户专属的业务规则。**这条规则不动 AI 模型、不动我们任何源代码**。"

---

## 步骤 4：现场验证（1 分钟）

回到总览页大屏。对着麦说：

> "现在开始巡检。"

客户能看到：
- 转写卡显示带标点的"现在开始巡检。"
- Node-RED 帧 debug 列闪一下（你刚拖的 function 节点命中）
- `av/control` 总线上对讲广播被推出（如果 intercom 接了，就听到"收到巡检指令…"）

> "刚才不到 1 分钟，没改一行 Python，加了一条业务规则。这是我们说的『**AI 能力 + 客户业务**用低代码粘合』。"

---

## 收尾话术（30 秒）

> "三个要点：
> 1. AI 理解结果是 **MQTT 标准协议**，不绑专有 SDK
> 2. 业务规则用 **Node-RED 拖拽**，工程师 1 天能上手
> 3. 客户的业务系统接进来 **不动 AI 内核**——AI 升级、业务变更，互不踩"

---

## 常见客户提问（销售备查）

| 客户问 | 答 |
|---|---|
| "我们 IT 没人会 JS" | function 节点只占 5%；多数场景用 switch / change / filter 节点拖拽即可，零代码 |
| "Node-RED 挂了怎么办" | 它跟 AI 内核解耦——挂了 AI 照常运行，业务规则恢复即重连 |
| "可以远程改吗" | 编辑器是浏览器界面，只要能到 `:1880` 端口就能改，支持权限隔离 |
| "规则误改了怎么回滚" | flows.json 是文本文件，git 版本控制，一键回滚 |

## 销售自检 checklist（演示前 30 秒）

- [ ] 大屏 `http://192.168.5.6:8800` 总览页 Node-RED 中控块**不是黑框**（如果是黑框 = 后台 plugin 没装好，找运维）
- [ ] 总览页转写卡有"等待中"或最近一句话（确认麦克风通路活）
- [ ] Node-RED 编辑器 `http://192.168.5.6:1880/` 能打开（看到流程图）
- [ ] 准备一句客户场景关键词（不要用"巡检"——按客户行业换：物流换"分拣"、医疗换"接诊"、商超换"补货"）
