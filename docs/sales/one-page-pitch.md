## 我们是什么

**一套"语音 + 视频 + 意图"统一的边缘 AI 中控平台**——把客户已有的语音系统、视频墙、IPC、智能家居"接到一根 MQTT 总线上"，用一句话或一个手势就能跨设备指挥。**完全本地化、可离线、国产硬件可选。**

## 三大能力（按客户付费意愿排序）

### 1. 纯转写 + 语义执行 —— 讯飞同款体验，去掉 50 万溢价
- 实时转写（FunASR 2pass，partial + 整句修正 + 标点 + ITN）
- 语义意图理解：自然话 → 设备控制指令（catalog 驱动 76 指令 prompt + 反幻觉白名单）
- **3588 NPU 端侧 LLM 首 token 198 ms / 解码 8.9 tok/s**（1.75 GB RAM）
- 兜底机制：LLM 慢 4.5 s 不出指令 → 自动走预设兜底，**演示不会翻车**

### 2. 视频深度理解 —— 不训模型也能识别行业目标
- **YOLOv8-World open-vocab**：客户给一句话（如 "person without hardhat / fire / smoke / safety vest"），系统直接识别，**0 标注、0 训练**
- Mac 端 36 ms/帧（演示极快），3588 端 1.6-1.8 s/帧（事件触发，不每帧）
- 实测可信场景：未戴安全帽（conf 0.31-0.36）、跌倒/站立姿态（0.67-0.80）、聚集打斗（0.41-0.81）
- 配合 Jetson Orin Nano + qwen2.5vl:3b VLM 做"看图说话"，文本 LLM 做不到

### 3. 跨品牌融合中间件 —— 利旧整合，不替换客户设备
- Playwright 自动登 husion HDC900 后台，**真实拿到 9 路设备 + 视频墙状态**（5/14 实测通）
- 256 个 husion API 已扫出，含视频墙切窗、信号源切换、预设场景一键切等
- 同样思路可接 海康 / 大华 / 华为家居 / 绿米 aqara —— **"我们做你设备之上的那一层"**

## 三个杀手锏（贴客户痛点）

### 杀手锏 1：语音 + 视频 + 意图统一中控
讯飞做语音、海康做视频、华为做家居 —— **没有谁把三者拉到一根总线上**。我们用 MQTT 做契约，模块解耦，客户旧设备照旧用。

### 杀手锏 2：化工 / 工地 / 安环 "零训练" 识别
客户说 "我要识别没戴安全帽的工人" —— 传统方案要标几千张图训几周。我们 `set_classes(['person without hardhat'])` 当场识别。
- 已实测命中可信：未戴安全帽、跌倒/站立、聚集打斗
- 真实痛点贴合：化工防爆区戴手套触不动屏 → 手势识别（MediaPipe）+ 远距离指挥

### 杀手锏 3：拿下旧系统 —— Playwright + 256 API 翻 husion 后台
客户已花几百万买的 husion 一体机，不要扔。我们 1 秒登进后台，**取 9 设备 + 切墙窗 + 预设场景一键切**。同样思路可推广到任何 web 后台的旧系统。
