## C. 可复制的设计原则（跨模块/跨项目）

1. **身份 ≠ 传输通道**：任何"名字/状态绑某路/某端口"的设计，先问一句"这条通道下面的实体会不会被上游动态重排"。答不准就找协议里的实体稳定标识（本例 = 包头 ID）。
2. **显示状态按"当前表"渲染，事件快照只作兜底**：SSE 重放/历史事件携带的是发生时刻的状态快照，直接显示必错乱（旧名满屏）。显示层一律 GET 当前表（/api/mic/names 模式）。
3. **归段/聚合的 key 用稳定身份，不用显示名**：两实体同名即 key 撞车 → 内容混段 → 交互改错对象（8/20 恶性循环实锤）。
4. **gate 复用**：静音门本为省 decoder，白捡了"录声音不录空气"的录音过滤——新增旁路功能先看现有管线里有什么可复用的闸门。
5. **就地改名交互模式**（点标签→内联输入→API 持久化+MQTT 热更新→全局刷新）可复制到摄像头名、设备名等一切实体命名。
